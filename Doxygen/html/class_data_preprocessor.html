void DataPreprocessor::fit ( const std::vector< std::vector< std::string > > & data)

Fits the preprocessor by determining column types and calculating normalization ranges.

Iterates through the dataset to identify numeric vs. categorical columns. For numeric columns, it finds min/max for normalization. For categorical, it maps unique strings to indices.

Parameters
dataDataset (2D string vector). The first row must be the header.
Note
This function populates internal maps and clears any previous state.

void DataPreprocessor::interpret_extracted_column ( const std::vector< float > & transformed_data) const

Decodes processed float data back into human-readable format.

Reverses normalization for numeric columns and picks the highest probability category (Argmax) for one-hot encoded categorical columns.

Parameters
transformed_dataA 1D vector representing a single sample of the extracted column.
Precondition
transform_and_extract() must have been called at least once to set the active column name.

Transforms the dataset using One-Hot Encoding and Min-Max Normalization.

Separates the dataset into a feature set and a specific target column.

Parameters
dataThe raw string data to transform.
column_to_extractThe name of the column to be used as the target (Y).
is_there_headerFlag indicating if the input 'data' includes a header row.
Returns
A pair of 2D float vectors:
  • first: Transformed feature matrix (all columns except the extracted one).
  • second: Transformed target matrix (the extracted column).
Precondition
The preprocessor must have been successfully fitted using fit().
