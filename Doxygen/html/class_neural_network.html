Initialize weights and biases for the neural network using Xavier uniform initialization, biases are initialized all to zero.

Parameters
input_sizeThe size of the input layer.
hidden_layers_numberThe number of hidden layers.
neurons_per_hidden_layerThe number of neurons in each hidden layer.
output_sizeThe size of the output layer.
initialization_methodThe method used for weight initialization (either "Xavier" or "He").
activation_functions_passedActivation functions for each layer - should match the number: hidden_layers_number + 1 (output layer). If invalid or empty, defaults are sigmoids
seedThe random seed for weight initialization.
